# `docs/` — website data

Generated and supporting files **served or fetched by the public site** (GitHub Pages).

Examples: Rumble feed JSON, TV/radio/shortwave schedule text, Podbean match map for radio play buttons, URL lists for scrapers, and hosted CMS widgets under `widgets/` (e.g. `Warning-Social-Media-Video.css` / `.js` for the main Rumble grid).
