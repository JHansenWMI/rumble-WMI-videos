# Country flags (itinerary)

Copied from historical CMS `Userfiles/Flags/` so the itinerary widget does **not** depend on the old host for flag images.

Public URL pattern:

`https://jhansenwmi.github.io/rumble-WMI-videos/itinerary-assets/country-flags/{filename}`

MediaSite maps country names → these files (see `media_archive_searcher/itinerary.py` `COUNTRY_FLAG_FILES`).

## Later: United States itinerary

US events use **state** flags, not country flags. Planned path:

`docs/itinerary-assets/state-flags/`

(with a similar name map, e.g. `washington.gif` / `hawaii.gif`).

Do not mix state flags into this `country-flags/` folder.
